# Beta 1.2

候选包，尚未发布。系统版本 `1.2.0-beta`，构建号 `6255`，计划发布标签 `v1.2.0-beta+6255`。

- 从首页打开搜索、从「我的」打开收藏，以及在消息中全页打开会话或头像时，旧页留在原位，新页从右侧覆盖。返回时原页自然露出，顶栏与底栏同步过渡。搜索连续提交只打开一个结果页，返回动画结束后再恢复输入焦点。
- 三屏番剧和影视详情的左侧简介支持下拉回弹。滚动时复用已绘制的内容，减少重复绘制。
- 快速切集或退出播放页时，及时取消已过时的播放地址请求，避免旧选集的画面、评论或后台播放信息覆盖当前内容。
- 下载暂停、重试和切换任务时保持文件与状态一致。续传前核对媒体来源和音视频编码，资源不匹配时保留已有数据并提示处理。多段 MP4 会提示暂不支持，避免只存了首段便显示完成。
- 我的订阅遇到缺少标题、UP 主或视频数量的条目时，显示可读的占位信息。离线缓存区分读取中、无数据与读取失败，读取失败后可重试。
- 「关于」的版本名称随打包版本生成，与发布标签一致。开发历程归纳为 Alpha 和 Beta 两个阶段。

专用鸿蒙模拟器已用于检查导航和番剧滚动。播放器依赖在该模拟器上不提供视频纹理输出，真实视频解码、弱网音画同步与设备帧率仍需真机验证。最终候选包的主机完整回归和签名检查已通过，剩余模拟器流程与最终包安装复验待完成。

验证范围见 [Beta 1.2 验证记录](https://github.com/2751833085/PiliPlus-Harmony/blob/harmony/v2.6-video-experience/docs/harmony/beta-1.2-6255-validation.md)。
