# Beta 1.0

首个 Beta 版本，内部构建 `3.0.0+6252`。此前全部发布统一归档为 Alpha，保留版本详情和源码标签，旧 HAP 下载撤下。

本轮聚焦稳定性：播放器快速切换与进度操作、下载取消与落盘失败、搜索和动态的异步响应、聊天页面生命周期、评论管理的旧索引错行、原生窗口监听与旋转快照释放。保留当前界面风格和布局。

更新检测只选择属于当前发布、已完整上传的签名 HAP；版本标识与关于页统一为 Beta 1.0。GitHub 自动构建固定兼容环境，并纳入全部 Dart 回归。

验证结果和未覆盖项目见 [Beta 1.0 验证记录](https://github.com/2751833085/PiliPlus-Harmony/blob/harmony/v2.6-video-experience/docs/harmony/beta-1.0-validation.md)。
