# 本地版本归档

每个版本保存说明、构建元数据与 SHA256。HAP 保留在本机，被 Git 忽略。

- [V1](v1.0.0/README.md)：UI 改造前的功能移植基线。
- [V2 RC1](v2.0.0-rc1/README.md)：鸿蒙体验候选版，Release 开发签名 HAP；已在 Mate XTS 覆盖安装和启动。

- [V2 RC2](v2.0.0-rc2/README.md)：统一界面与紧凑播控候选版。

- [V2.5 RC1](v2.5.0-rc1/README.md)：可手动开启的竖屏短视频，包含 V2 RC2 全部调整。

- [V2.6 RC1](v2.6.0-rc1/README.md)：展开全屏刷视频、第一条下拉刷新与可选海外模式。

- [V2.6.1 RC1](v2.6.1-rc1/README.md)：竖屏操作修正、独立左右滑配置与下一条媒体预加载。

- [V2.6.2 RC1](v2.6.2-rc1/README.md)：平稳分页、快速滑动保持播放器、短视频自动播放。

- [V2.6.3 RC1](v2.6.3-rc1/README.md)：简洁模式保留进度条，播放/暂停移至底部。

- [V2.6.4 RC1](v2.6.4-rc1/README.md)：模式切换过渡、紧凑评论、缩小图标及不想看原因选择。

- [V2.6.5 RC1](v2.6.5-rc1/README.md)：按比例进入短视频、连续预取与参考 iOS 的布局。

- [V2.6.6 RC1](v2.6.6-rc1/README.md)：短视频暂停信息层、中央播放与时间。

- [V2.6.7 RC1](v2.6.7-rc1/README.md)：图标数量与紧凑关注布局。

- [V2.6.8 RC1](v2.6.8-rc1/README.md)：关联搜索与独立弹幕入口。

这里是本地 Git 版本库，不代表已经发布到 GitHub 或应用市场。
