# V3 Beta 6218

- 首页首批推荐缩减为按列数请求 8–20 条（App 接口以服务端返回页为准），首批返回立即展示，滚动后再补充，不再为凑满数量等待多轮请求。以缩短到 1.5 秒内为目标，但不提前结束未完成的网络请求，实际速度仍受接口和网络影响。
- 增加持续缓冲且进度停滞的有限恢复：约 10 秒后尝试原位置重开，至少间隔 15 秒，连续最多两次。恢复串行处理，检查播放源归属，不主动恢复用户暂停的视频；后台、拖动进度、直播及本地视频不触发该自动恢复。
- 修正播放中途请求失败时仅判断“缓存为零”的条件，过期播放源的延迟重试不会干扰新视频。
- 每次切入“我的”静默更新数据，合并同时发起的刷新；重新启用下拉刷新，保留滚动位置。
- 消息页内部打开聊天详情增加与其他页面一致的横向进入动画；折叠形态切换不重播动画，保留草稿和焦点。

开发签名 HAP 仅适用于签名允许的设备，其他设备需自行签名。本版仍为 Beta；未承诺所有网络下的刷新耗时或彻底消除底层解码器问题。
