- 经典底栏改为鸿蒙原生绘制，与首页顶栏共用同一个薄材质背景组件、系统模糊类型和遮罩颜色；底栏仅反转渐变方向。
- 删除经典底栏的 Flutter 实时高斯模糊，旧 SDK 与初始化阶段保留灰色实色回退。

- 修复弱网视频耗尽但音频继续的漏报：检测视频进度与视频缓存、保留播放意图并显示加载，缓存恢复后在卡住的位置重新同步；暂停、拖动、切换视频会取消旧检测。打开和重试统一缓冲参数。

本次减少了 Flutter 渲染链路的模糊工作，原生材质在背景变化时仍可能重绘；不作零开销或帧率已改善的保证。
