# V3 Beta 6243

- 新增“右侧统一显示相关视频和评论”，默认开启；平板右侧顶部页签可点击或左右滑动切换，视频详情固定在左侧视频下方。关闭后恢复原位置偏好。
- AI 总结在播放页右侧展开，与评论使用相同的过渡；侧滑和返回只关闭总结，不退出视频。
- 普通视频页保留底栏，并预留底部空间、拦截穿透触摸；全屏播放仍隐藏导航。
- 增加缓冲后音频时钟停滞的有限自动恢复，保留用户暂停和音量选择，不替换视频源。该保护不能判断音频时钟正常但扬声器失声的情况，偶发失声仍需真机验证。
- 评论图片长按菜单和图片预览长按菜单取消震动，保留分享、复制链接及保存。
- 底栏沉浸光感补充性能提示：开启后会增加性能消耗，可能出现卡顿，请谨慎开启。

验证：274 项 Harmony 回归测试通过，含右侧面板定位、慢速侧滑关闭、顶部页签切换、默认设置与强制详情位置、缓冲音频恢复策略和底栏路由规则。静态检查无错误、无警告。真机调试暂未检测到设备，底栏触摸、缓冲失声和实际帧率尚待设备验证。
