# V3 Alpha 6249（测试构建，未公开发布）

> Alpha 历史记录：本阶段不再提供安装包，以下详情与验证结果保留用于追溯。旧路径和构建号不变；首个 Beta 版本为 [Beta 1.0](../beta-1.0/notes.md)。

- 新增「外观设置 → 交互与动画 → 下拉刷新灵敏度」，默认轻拉，可切换标准和较重；松手触发，保留星球渐显、渐隐和回弹。
- 减少页面进退时原生顶底栏的重复状态同步；完全被新页面覆盖的底栏停止绘制，返回时保留原布局随页面露出。
- 沉浸按钮的高光改为局部重绘，静止控件不再逐帧重建；搜索框的移动、弹性和光感保持原样。
- 修复嵌套页面整体卸载时可能重复订阅已结束路由的问题，补上快速进退、手势取消与路由卸载回归。
- 清理已停用的智感握姿、旧浮动底栏、Material You 切换、无效音量设置、普通播放器上的短视频监听，以及已停用的网络变化自动重载代码。现有功能与账户数据保留。

验证：344项适配回归通过；同一生产包在鸿蒙7模拟器完成15分钟连续导航，42轮、636次操作校验；三档刷新设置保存、两次冷启动进退检查通过。

真机覆盖安装通过，原UID和首次安装时间保持。真实播放、弱网音画同步及实际掉帧验证尚未完成；模拟器不支持当前播放器的视频纹理输出，不能替代真机验收。完整范围见[6249验证记录](https://github.com/2751833085/PiliPlus-Harmony/blob/harmony/v2.6-video-experience/docs/harmony/6249-validation.md)。
