# 6212 滚动优化

- 鸿蒙纵向 CustomScrollView 刷新改为 sliver 预留空间；移除整张列表的外层位移和强制夹紧滚动。
- 使用与我的页面相同的 BouncingScrollPhysics + AlwaysScrollableScrollPhysics，普通上下滑动、顶部和底部回弹由单一 ScrollPosition 驱动。
- 顶部拉到 72vp 后松手刷新，加载时保留 64vp 空间；星球先渐隐，再由滚动物理回收。
- 程序触发刷新也可显示加载空间，重复调用合并；异常后可再次刷新。
- 只在顶栏收起/展开或底栏隐藏状态变化时发原生消息，原生顶栏启用时不再另行纠正滚动坐标。
- 动态大卡片关闭整块触摸高光重绘，按钮效果保留。未降低图像或整屏分辨率。

验证：三种屏幕宽度的弹性、松手刷新、底部回弹，以及与普通弹性列表逐步位移对比通过；手动刷新、顶栏避让、失败恢复测试通过。导航与外观回归通过。

本轮没有实机帧率采样或触控测试，不把自动测试视为流畅性已完全验证。
