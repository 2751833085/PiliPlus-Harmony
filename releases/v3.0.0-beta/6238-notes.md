# V3 Beta 6238

- 底栏改用更接近顶栏的中性薄磨砂，移除原来的灰色斜向卡片色调；保留单层、局部裁剪的模糊，原生悬浮栏提高材质清晰度。
- “底栏半透明磨砂”改名为“底栏沉浸光感”，默认开启，仅在总“沉浸光感”开启时显示，并紧接其下；关闭总开关保留子选项偏好。
- 折叠屏能力由系统硬件接口识别，普通手机/平板上的折叠专用选项禁用并说明无效；折叠状态跟随也增加能力检查，不以窗口宽度冒充硬件能力。
- 评论偏好新增默认关闭的“显示评论点踩数量（实验性）”；视频和评论开关均注明“不一定有用，哔哩哔哩可能不提供或使接口失效”。未得到可信总数时显示“未公开”，不将本人的点踩状态、回复数或零占位当作总数。
- 长按封面弹窗从首帧就固定预留封面比例；有封面尺寸时采用尺寸比例，普通视频缺失元数据时用 16:9，番剧海报用 3:4。加载成功/失败不改变框高，完整图片保持 contain。
- 视频播放页顶栏恢复黑色与浅色状态栏图标。下方横向合集列表为每个未选视频加入边框，保留当前播放项强调色。

点踩研究：哔哩哔哩技术文章说明平台内部存储点踩计数，但没有在该文章中提供公开查询接口（https://www.bilibili.com/opus/758312609901445367）。当前应用使用的 ReplyInfo 协议只含点赞量与个人操作状态，不含点踩总数。此前抓取的视频响应含 dislike: 0，本轮直接复查公开接口被 HTTP 412 拒绝，无法独立核实实时数量。暂未发现可靠可用的公开获取路径；不增加逐评论请求，也不捏造数量。
