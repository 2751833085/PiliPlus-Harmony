- 平板视频页右侧加入细分隔线与间距；UP 主头像与评论头像统一为 34 dp，重新整理名称、标题、统计和点赞等操作的字号与间距。
- 合集/分 P 的“展开全部”防止连续点击重复打开。合集下方滚动区域独立裁剪，避免按钮墨水效果越过播放器边界。
- 长按封面预览按图片实际比例完整显示，兼容横图、方图和竖图；内容保持不透明，窗口外点击关闭。

- 经典底栏增加局部低强度磨砂，原生悬浮底栏移除遮挡材质的实色底；保留按压反馈，不增加全屏模糊层。写评论输入弹窗统一使用单层磨砂和沉浸光感。
- 播放器根据实际返回的视频流选择画质与编码，避免引用缺失的档位；修正空音轨残留、音轨设置异步顺序、播放重试缺失请求头和音轨地址多余引号。AI 原声翻译菜单使用正确名称，切换保留播放位置。

- 播放器设置新增“平板视频信息位置”：默认在左侧视频下方，也可切换为右侧上方；单屏仍保持原有布局。AI 总结入口与播放统计在同一行对齐，窄栏自动换行。
- 外观设置新增“底栏半透明磨砂”，默认开启；关闭后使用不透明材质并保留按压高光。
- 评论详情使用与 UP 主侧栏一致的右侧进入/原路退出动画。UP 主头像图片长按保存取消震动。
- 原播放源仍可用时返回页面直接恢复；切换源和网络重试共用串行队列，跳过过时请求，防止旧视频进度覆盖上一条记录。全屏缩放期间复用简介/评论/推荐组件并隔离绘制，保留现有动画时长与曲线。
- 修复鸿蒙亮度事件为空值或非 double 时的异步异常，并正确取消监听。
- 播放器设置新增默认关闭的“显示视频点踩数量（实验性）”。仅显示接口提供的有效数值；当前公开接口的占位 0 不视为真实零，未获得数量时显示“未公开”，不估算。
