# 6214 滚动性能与底栏材质

## 最终约定

- 底栏采用不透明底色和与“我的”界面相同的表面渐变，取消该处实时背景模糊。
- 三个导航按钮各自保留触点高光，并加入 150ms 的轻量缩放反馈（按下 0.94，释放恢复 1）；底栏不位移，不参与拖动。系统减少动态效果开启时不缩放。
- 长按封面弹窗不虚化背景，保留遮罩及点击外部关闭，过渡缩短到 160ms。
- 其他弹窗、搜索控件继续保留模糊与沉浸光感。顶部大面积渐变模糊改为轻量原生背景模糊，仍需验证最终性能。
- 首页和动态封面解码密度上限从 1.5 调到 2.25，单轴上限从 768 调到 1280；不改封面比例及刷新动画。

## 已采集的诊断（不是最终版本验收）

Mate XTs，展开横屏，3184×2232。原 6213 首页稳定滚动批次 raster 中位数约 12.0–12.6ms，“我的”约 3.8–5.2ms。系统 trace 显示首页 AcquireNextSurface 等待显著高于“我的”；Dart build 时间很短，因此重点是绘制与合成负载。

临时去掉大面积模糊的 A/B 版本首页批次 raster 中位数约 3.2–3.8ms、动态约 6.5–7.2ms。这个临时版本不能代表最终版本，也不用于证明所有场景不卡顿。最终保留顶部模糊并换用不透明底栏后的数据尚未采集。

FrameTiming 是绘制耗时，不等于实际呈现帧率；系统报告刷新率与实际刷新率存在差异，不能直接以 16.67ms 推算掉帧。
