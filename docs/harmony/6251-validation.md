## 优化依据与 6250 基线

参照 Flutter 的[性能最佳实践](https://docs.flutter.dev/perf/best-practices)减少重复构建和裁剪层，不改变现有视觉动画。[华为帧分析文档](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/ide-insight-session-frame/)用于区分应用、渲染和系统显示链路；本轮没有使用全页截图缓存或以降低封面清晰度代替定位。

在修改前的 6250 上，全局光感保持开启，仅对底栏光感开关作顺序对照。每种材质各 3 次保留数据冷启动、15 次暖态设置进退，36 个完整路由区间，6 段 trace，无环形缓冲截断。开启时暖态进/退超过 25ms 的相邻 DoDraw 启动间隔为 5/292、10/281；关闭后为 3/292、7/286。最大返回间隔 57.009ms 降至 38.310ms，但样本是一次顺序对照，不能归因于材质。

开启组最大返回间隔中，系统 SendVsyncTo 比 VSync 时间戳晚 43.010ms，随后 0.117ms 到达 Flutter，1.135ms 后开始 UI。UI 与栅格片段均不足以解释全部空档；没有足够线程调度数据确定系统发送延后的根因。相邻引擎帧、DoDraw 与 VSync 统计不是实际呈现帧率，也不是实体手机的掉帧结论。原偏好已恢复。详见[完整基线](qa/6251-settings-baseline-6250.md)与[数据](qa/6251-settings-baseline-6250.json)。

## 6251 模拟器复验

6251 从 6250 覆盖安装，保留 UID、首次安装时间和数据；全过程仅使用专用 DevEco 模拟器，没有操作实体手机。[安装记录](qa/6251-emulator-install.json)。

相同光感开启条件下，6251 完成 3 次冷启动与 15 次暖态设置进退，36 个路由区间均通过，6 段 trace 无截断。暖态进入 UI P95 从 3.521 降至 3.258ms，返回从 4.055 降至 3.895ms；相邻 DoDraw 超过 25ms 的次数分别为 5/291 与 6/285（6250 为 5/292 与 10/281）。但冷启动进入标记到首个配对栅格片段结束，从 12.287–19.864ms 变为 25.646–29.589ms；进入的最大帧间隔也未改善。因此仅确认减少重复工作，不能宣称整体转场问题已解决。[完整对照](qa/6251-settings-transition-comparison.md)、[帧统计](qa/6251-settings-transition.json)、[间隔分析](qa/6251-settings-gaps.json)。

对 6250 的 57.009ms 最大间隔进一步核对，Flutter 的下一帧请求于 9069.015760 发出、Render Service 于 .015870 收到，早于系统报告的 .027179 VSync 时间；直到 .070180 才出现 GenerateVsyncCount 标记，9µs 后发送。因此该样本可排除 Flutter 晚请求，仍不能区分同步源、系统线程调度或模拟器宿主停顿。

使用官方折叠状态切换，在同一实际结果页连续验证 3184×2232、2048×2232、1008×2232，DPR 均为 2.875，未修改 DPI 或拉伸截图。真实网络搜索结果的单列、右栏热搜/发现和折叠后保留内容均通过；单屏游客「我的」外框去除、底栏完整与顶部安全区通过。模拟器出现小艺输入法首次协议时仅取消，之后用应用已有的公开搜索链接进入结果；未验收键盘输入，也未覆盖登录后收藏/历史的真机数据。后者由实际 MinePage 的自动回归覆盖布局。[视觉检查](qa/6251-search-mine-visual.json)。

持续导航与滚动运行 600.002 秒，27 个完整循环，417 次操作均验证通过，截止时无待确认操作。覆盖首页、动态、我的、设置进退，以及推荐、热门、分区切换与前后滚动。全程 PID 保持不变，结束后恢复三屏推荐首页，原有光感偏好保持开启。[验证汇总](qa/6251-qa-summary.json)。

后半程五次 PSS 采样为 405,236–464,614KB，末次 434,601KB；窗口有限，不据此断言无泄漏。保留日志覆盖测试开始后约 1.665–596.853 秒，应用 PID 去重 1,018 行，在有限异常、布局溢出、ANR、致命信号与退出关键词中未匹配到异常。系统筛选日志也无同时匹配应用/PID的记录；这不是完整日志审计或零崩溃保证。[运行观测](qa/6251-runtime-observation.json)。

本轮没有操作实体手机。模拟器的播放器纹理受插件限制，未验收实际视频解码、音画同步、弱网播放或下载；没有实际呈现帧率测量，偶发转场长帧仍需继续定位。
