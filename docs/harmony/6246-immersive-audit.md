## 继承主题与局部材质

全局 `HarmonyTheme.apply` 提供颜色、字体、AppBar、对话框边界和按钮触点反馈。普通 `Material + InkWell` / `ListTile` 不会因为继承主题就自动具有跟随手指的光感，需单独适配。模糊仅用于需要采样背后的弹层，普通滚动行使用缓存材质或仅触点高光。

## 控件与模糊边界

- 新增 `ImmersiveRowInteraction` 仅包裹实际历史、收藏夹、稍后再看、会话和普通设置行。强制 `allowMovement: false`，不添加背景、形状、模糊或新的手势识别器；只有原有搜索框保留移动效果。
- 沉浸关闭、高对比或减少动态效果时，行包装直接返回原控件，不创建额外反馈控制器。嵌套按钮由已有最深层 pointer-owner 规则处理，避免两层同时发光。
- 普通、滑块、双滑块、多选、顺序多选设置弹窗均在实际 `AlertDialog` 构造处接入共享材质；CDN 选择器复用普通选择器。不开启沉浸或使用无障碍降级时不启用实时模糊。
- 同一次 SDK 菜单的非重叠条目共享一把局部 `BackdropKey`；嵌套、独立或重新打开的菜单使用不同 key。保留原 sigma 24、渐变、透明度及外圆角，不能据此直接宣称获得了具体帧率提升。
