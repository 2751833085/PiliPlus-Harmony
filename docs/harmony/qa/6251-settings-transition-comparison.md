# 6251 设置页转场复测

对照 6250 原始光感开启组。在同一 DevEco HarmonyOS 7 三折屏模拟器、3184×2232、DPR 2.875 的游客状态下使用 6251 生产签名包。覆盖安装保留数据。全局与底栏沉浸光感实读均开启，测试期间未切换。

两版各记录 3 次应用冷启动后首次设置进出、15 次暖态进出。两版各有 36 个完整 Navigator 路由区间、6 段未截断原生时间线，均确认「我的 → 设置 → 我的」。冷启动保留磁盘缓存。

| 路由 | 6250 / 6251 配对栅格数 | 6250 → 6251 UI BeginFrame P95 | 6250 → 6251 DoDraw P95 | 相邻 DoDraw 启动间隔 >25 ms，6250 → 6251 | 最大间隔，6250 → 6251 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 冷启后进入 | 59 / 58 | 3.022 → 3.482 ms | 17.296 → 17.105 ms | 1/56 → 1/55 | 25.531 → 38.265 ms |
| 冷启后返回 | 59 / 60 | 3.417 → 3.135 ms | 17.265 → 17.291 ms | 2/56 → 0/57 | 35.116 → 20.054 ms |
| 暖态进入 | 307 / 306 | 3.521 → 3.258 ms | 17.261 → 17.248 ms | 5/292 → 5/291 | 38.588 → 40.456 ms |
| 暖态返回 | 296 / 300 | 4.055 → 3.895 ms | 17.217 → 17.272 ms | 10/281 → 6/285 | 57.009 → 39.892 ms |

从 Navigator 进入标记到首个匹配引擎栅格片段结束，三个冷启样本从 12.287–19.864 ms 变为 25.646–29.589 ms。暖态进入的 UI P95 降低，长间隔次数相同，最大间隔略长；暖态返回长间隔次数减少。样本不支持把进入与返回都概括为改善。

6251 最长暖态进入间隔 40.456 ms，与对应系统 SendVsyncTo 的相邻发送间隔 42.169 ms 同时出现；发送到 Flutter 接收只花 0.178 ms。最长暖态返回间隔 39.892 ms 对应系统发送间隔 39.936 ms，发送到接收为 0.092 ms。两版均能看到系统发送前的供帧空档，缺少更细的调度和应用表面呈现关联，不能确定系统、宿主或具体控件的根因。

表中是 Flutter 引擎和系统跟踪标记，DoDraw 可包含 SwapBuffers 等待，不能当作 CPU/GPU 持续工作或屏幕实际 FPS。两版按顺序各采一次，宿主负载与缓存状态未随机化。没有实测真机显示或输入到屏幕的端到端延迟。
