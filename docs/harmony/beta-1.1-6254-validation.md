# Beta 1.1 · 构建 6254 验证记录

系统版本为 `1.1.0-beta`，应用和发布名称为 Beta 1.1。

## 改动范围

- 单屏我的页面去除叠加边距：外层 8dp、内容 8dp，头像、分区标题、预览封面统一离边 16dp。使用两个轻量分组，不增加实时背景模糊；双、三屏沿用原有分栏和材质。
- 搜索分类与筛选头部保留位置；结果区域复用统一星球加载，加载完成后渐隐、结果淡入。已加载数据翻页不重新触发入场动画。筛选菜单统一沉浸材质和深浅色，保持原有筛选功能。
- 专栏/图文和动态详情的横向操作条归属右侧评论面板，避免滚动时铺满正文下方；统一页面内的中性表面颜色。
- 设置备份保留两份设置数据盒，补充本地弹幕屏蔽规则；导入先校验再写入。登录备份保留全部已存账号及四类账号角色，兼容旧文件。

## 备份边界

设置包括当前外观、折叠屏、推荐、播放器、字幕、弹幕、网络等已持久化偏好及本地弹幕规则。登录备份包含可复用凭据和角色选择。设置中保存的 WebDAV 凭据也随设置导出，两类文件都为明文。

不包含下载媒体、离线进度、缓存、系统权限、桌面卡片设备标识和字体二进制文件。新设备的自定义字体需要重新导入。服务器收藏、稍后再看、观看记录、私信等由账号服务提供，不能通过配置备份复制。普通搜索历史、本地评论有各自导出入口，不合并进本次设置备份。
