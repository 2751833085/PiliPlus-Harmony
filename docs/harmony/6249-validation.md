## 持续测试

同一份生产包完成 900 秒导航工作负载，含收尾证据落盘共 901.258 秒；42 个完整循环，637 次尝试中 636 次得到目的页或滚动位移验证，截止边界的一次滚动未验证，不计通过。覆盖底栏首页/动态/我的、设置进退、推荐/热门/分区及上下滚动。全程同一 PID，未因未知页面或进程退出而中止。见 [连续导航记录](qa/6249-navigation-soak.json)。

测试驱动最初因本机沙盒无法访问 HDC 而停止，0 次输入；另一次因热门快捷入口被隐藏导致断言过窄而停止。两次均通过现场界面核对修正测试定位后重新启动，不计为应用故障，也不并入最终 42 轮。

827.6 秒内共 16 次只读内存采样，PSS 存在增长与自然回收，不能仅用它们证明没有泄漏。指定 PID 当前保留日志中未匹配到 Unhandled Exception、MissingPluginException、RenderFlex overflow、setState-after-dispose 或 fatal-signal 关键词；该检查不是全部日志和全部故障的审计。详见 [资源与有限日志检查](qa/6249-runtime-observation.json)。

新设置专项：在模拟器实际菜单中按「轻拉 → 标准 → 较重 → 轻拉」逐项选择并读回；退出设置重进后保持轻拉，共18次验证，最后恢复默认轻拉。见 [设置检查](qa/6249-sensitivity-ui.json)。菜单行的无障碍树标为 Text/clickable=false，测试通过现场画面和标题唯一性确认触摸区域；这是测试定位限制，不作为屏幕阅读器支持通过。

搜索入口得到页面树验证；随后小艺输入法首次使用协议接管窗口，选择取消并退出输入法后恢复首页，没有代用户接受协议。关键词输入与搜索结果未验证。

热启动视频页进入及首个详情树确认后立即返回，2次操作通过。两次主动冷启动分别以设置、视频优先，均完成14次操作验证，并再次读回「轻拉」，最后回推荐首页。冷启动刻意更换了PID，不计为崩溃；HDC与页面树校验时间不等于动画时长或FPS。见 [专项检查](qa/6249-followup-checks.json)。

发布前再次尝试启动实体手机，系统返回10106102（屏幕锁定，开发者模式不能自动解锁）。没有关闭开发者模式、绕过锁屏或修改屏幕超时。

手机仍需解锁后执行真实播放、弱网音画同步和物理设备流畅性验收。当前视频依赖在模拟器上主动禁止纹理输出，因此模拟器的视频页检查只覆盖布局和返回，不验证解码及声音。
