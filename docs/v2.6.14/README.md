# V2.6.14 · 播放模式防误切

本轮先针对普通播放误进入竖屏短视频处理。用户所称“便携模式”尚待确认；未将代码中的潜在触发路径等同于已复现的真机根因。

播放栏渐显/渐隐、滑入/滑出时暂不接收点击，只有完整显示时按钮可用。透明或移动中的模式入口不再拦截视频点击；竖屏与全屏按钮在锁定、拖进度、长按倍速期间拒绝模式切换。

迟到的视频尺寸信息只能在尚未操作的初始普通页决定一次短视频布局。操作后、全屏中、系统小窗/画中画中、页面被覆盖或应用在后台时，不再被自动换页。已知竖屏视频的初始自动入口和明确点击竖屏按钮仍保留。模式请求串行处理，退出全屏的等待结束后复核当前视频、可见状态和设置，避免过期请求生效。

验证包括真实 AppBarAni 的透明/中间帧/完全显示/关闭过程点击命中测试，以及首次比例判断和自动入口抑制回归。系统小窗或单手模式的误启动需待用户明确界面后进一步定位，不擅自关闭既有后台画中画功能。
