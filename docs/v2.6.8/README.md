# V2.6.8 · 底部搜索与弹幕入口

短视频的信息区新增「搜索 · 关联词」行，点击进入原有搜索结果页。关联词来自当前视频已有标签：优先选择标题中出现的更具体标签，其次选择普通标签；排除 BGM 发现标签，没有标签时使用完整标题。显示可省略，搜索参数保留完整词。换视频重新取标签时清掉旧值，晚到响应沿用 BVID/CID 来源校验。

这是基于当前视频元数据的本地选词，不是对官方私有搜索推荐接口的接入；复用原有标签请求，不新增阻塞播放的网络请求。

底部改为短胶囊「发弹幕」、弹幕开关、弹幕设置，右侧保留普通详情和全屏。输入入口最大 220dp，手机上为旁边按钮留出空间；点击仍打开原有发送面板，保留登录、UP 关闭弹幕校验、草稿与播放暂停/恢复逻辑。开关控制现有显示状态，设置直接复用完整播放器弹幕设置，无须先打开三点菜单。

搜索与合集行采用统一的圆角和间距。窄屏、大字号及低高度窗口继续允许滚动信息区；底栏与进度条位置固定，不改变视频矩形或重建播放器。包括 V2.6.7 及此前全部功能。
