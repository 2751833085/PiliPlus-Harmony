# V2.6.16 · DevEco 运行回归

本轮使用 DevEco 官方 HarmonyOS 7.0.0 / API 26 三折屏模拟器运行真实 HAP，以未登录状态检查网络页面和操作流程；没有用组件截图代替整页运行，也没有清理手机账号。

- 去掉短视频缓冲预取完成时的整页重建，相邻首帧仍由预览更新事件更新。
- 将 mpv 文件缓存放入鸿蒙应用临时沙箱，目录不可用时回退到现有容量限制的内存缓冲；等待初始化选项设置完成后再创建视频控制器。
- 修复浅色应用中短视频评论标题的低对比度，以及评论正文和标题栏背景不一致。深色面板显式建立文字和 Material 表面。
- 显示参数采集支持指定 HDC 目标与模拟器来源，避免手机和模拟器同时连接时误操作。

完整 Flutter 回归 125 项通过，Dart 静态检查 0 错误、6 项既有警告，原生握姿/折叠回归通过。签名 Release HAP 已生成，详见[版本归档](../../releases/v2.6.16-rc1/README.md)和[验证记录](VALIDATION.md)。

播放器依赖在模拟器中主动拒绝创建视频输出，已通过日志和 Dart VM 状态确认；模拟器的黑色画面不能用于验收解码、首帧和连续播放流畅度。这些仍需 Mate XTS 真机完成。
