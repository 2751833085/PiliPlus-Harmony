# V2.6.1 · 竖屏操作与下一条预加载

版本 `2.6.1+6087`，继承 [V2.6](../v2.6/README.md) 的展开全屏、首条下拉刷新与海外模式。竖屏短视频仍由「设置 → 其他设置」手动开启。

## 操作

- 双击视频画面：播放 / 暂停，不再点赞。
- 单击画面：隐藏头像、简介、右侧操作和上下信息栏，仅保留播放按钮与时间；再次单击恢复。隐藏信息层时不改变视频尺寸。
- 默认左滑、右滑均调整进度，信息层显示与隐藏时相同。上下滑切换视频，首条手指下拉刷新并换成新的第一条。
- 「其他设置 → 竖屏短视频」可分别配置左滑和右滑：调整进度、打开评论区、打开作者视频页。例如左滑评论、右滑作者；选择后该方向不再同时调进度，短距离和取消的拖动不会误打开页面。
- 评论沿用弹层；作者入口直接选择该作者的投稿页。页面返回保留原视频。上半屏长按打开播放器设置，下半屏长按沿用倍速。
- 关闭竖屏模式后，普通详情和播放器继续沿用既有操作。竖屏信息流的全屏状态也采用自定义左右滑，但保留完整全屏控制栏及锁定行为。

## 预加载

「预加载下一条视频」默认开启，可在同一分区关闭。当前播放器缓冲稳定后，预取下一条的播放地址、作者/标题，以及最多 2 MiB 视频头部与 256 KiB 音频头部。预取遵守当前帐号、画质、编码、语言及线路设置；不通过降低画质提速。

已预取的媒体通过仅绑定本机回环地址的 Range 服务交给现有原生播放器；播放超出缓存时从原 CDN 接着读取，缓存头部不会再次下载。不增加第二个播放器。仅保留当前与下一条的至多四份媒体头部，正常上限约 4.5 MiB，不落盘；这是缓存预算，不是整个播放器的内存上限。

当前视频缓冲不足时暂停预取，恢复后可复用已取得的元数据；切换帐号/画质等上下文、退出页面、进入后台会隔离或取消旧任务。预取总预算 8 秒、元数据有效期 45 秒；预取失败不阻塞正常取流。提前滑走可能只命中元数据或部分媒体，不能保证任何网络都零等待。取消读取也不代表服务器忽略 Range 时网络层严格只接收指定字节。

非当前页不再固定显示「正在打开视频」，保留封面过渡；真实播放错误与刷新状态仍可见。缓存播放出错时有限次回退实际 CDN，并尽量保留进度及播放意图。海外模式继续独立控制，默认关闭。

## 原版核实与验证边界

[Bilibili 竖屏操作教程（2023-10-13）](https://www.bilibili.com/video/BV14p4y1u7sH)介绍切换为双击暂停、单击沉浸以及横向调进度；本版按用户最新确认采用这一操作，并增加独立左右滑设置。历史教程不能证明当前各平台 Bilibili 版本完全一致，也没有据此声称复制其内部预加载实现。

组件与本地 HTTP 测试验证手势、隐藏层命中、单播放器保留、缓存复用、Range 拼接和取消。原生解码首帧时间、海外网络吞吐与连续滑动性能需要真机运行测量，不能由测试替代。见 [验证记录](VALIDATION.md)。
