# V2.6.7 · 作者与右侧操作布局

右侧点赞、评论、投币、收藏、分享保留图标与真实数量；数量缺失时留空，不再显示名称或伪造数字。读屏仍提供完整名称和操作。数字区保留固定空间，大字号数字过宽时缩放至可用宽度，避免数量加载造成位置跳动。

关注胶囊紧随作者信息，间距 10dp，不再由整行剩余空间将按钮推到右侧。头像保留 36dp，作者文字按内容收缩，长用户名在可用范围内截断；关注与已关注沿用现有业务及位置。

## 按比例验证

使用真实短视频组件与模拟播放画面，覆盖 3:4、9:16、16:9；画面按源比例完整放入视频区域，自动留黑边，不再以无比例的黑色占位代替视频。

参考截图的屏幕宽高比对应 392×853⅓ 逻辑尺寸，另测 390×844、320×640、840×800、600×320。模拟顶部 32dp、底部 24dp 安全区；窄屏、展开屏和矮窗口另用 1.8 倍字号。头像、粉丝数和操作数量齐备，另覆盖缺失数量、长用户名与已关注状态。

[3:4 暂停预览](previews/phone-paused-3x4.png) · [9:16 竖屏预览](previews/phone-9x16.png) · [16:9 手动进入短视频页预览](previews/phone-manual-16x9.png)。横屏内容的默认入口仍是普通详情页。

这些安全区是测试参数，未声称是 Mate XTS 实测值；画面为标明比例的测试图形，不代表真机解码视频。包含 V2.6.6 及此前所有功能。
