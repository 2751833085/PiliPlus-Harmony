# Beta 1.0

PiliPlus Harmony 的首个正式测试版。系统版本 `1.0.0-beta`，构建号 `6253`，发布标签 `v1.0.0-beta+6253`。

> 本版已由 [Beta 1.1](https://github.com/2751833085/PiliPlus-Harmony/releases/tag/v1.1.0-beta%2B6254) 取代，不再提供安装包。软件仍在测试阶段，功能尚不稳定。

## 软件简介

PiliPlus Harmony 是 [PiliPlus](https://github.com/bggRGjQaUbCoE/PiliPlus) 的鸿蒙版，一个使用 Flutter 开发的哔哩哔哩第三方客户端，为手机、平板和折叠屏适配。

- **原有功能**：推荐、热门、分区、番剧/影视、动态、搜索、评论、私信、个人主页、收藏、历史、稍后再看和离线缓存等，均来自上游。
- **鸿蒙界面**：可选的鸿蒙设计风格、原生顶栏与底栏、悬浮 Dock、沉浸光感材质和星球加载动画；关闭后恢复原版界面，不影响账号和设置。
- **折叠屏布局**：导航、首页栏数、搜索和视频页按窗口尺寸自动调整；折叠、展开时保留页面状态、滚动位置和播放进度，并避让安全区与挖孔。
- **播放器**：重新编译的鸿蒙原生 mpv，支持音量均衡与 Audio Vivid；提供弹幕、字幕描边、合集/分 P、空降助手、AI 总结和海外线路。
- **竖屏短视频**：可选的上下滑信息流，复用同一播放器，支持预加载、评论、选集和普通/全屏切换。
- **系统能力**：动态照片保存、分享、画中画、后台播放、接续和智感握姿。

## 开发历程

Beta 1.0 之前共经历约 70 个内部构建，主要改动汇总如下。

### 移植基础

- 汇合 PiliPlus 上游业务更新与鸿蒙社区适配，生成 ARM64 HAP。
- 按窗口宽度在底栏与侧栏间切换导航，折叠、展开时保留页面和滚动位置。
- 新增动态照片保存、字幕描边、音量均衡和 Audio Vivid 解码。
- 固定 Flutter OH、SDK 与原生播放器来源，加入构建、哈希校验和许可打包流程。

### 鸿蒙界面

- 可选鸿蒙风格：设置面板、大屏分栏、开关、弹层、输入框、按钮和滑块。
- 原生顶栏、底栏和悬浮 Dock 共用薄材质背景；沉浸光感覆盖播放设置、菜单、选集、我的和关于页。
- 星球动画贯穿下拉、刷新和收回；加入下拉刷新灵敏度设置，默认轻拉。
- 统一贴底菜单、圆角裁切和深浅色表面；设置分组整理，冲突选项会说明原因。
- 关于页加入开发历程，并注明“厄斯因二次编辑”。

### 首页与导航

- 首页栏数按窗口形态和方向自动选择，可手动覆盖；首屏固定 16 条推荐，后续按需补充。
- 刷新、分页加载和底部安全区重新设计，最后一排内容可完整滚动到底栏上方。
- 页面转场统一为右侧进入、反向退出，时长 300ms；原生顶栏与底栏随页面同步移动，避免闪烁和触摸穿透。
- 搜索按单屏、双屏、三屏重新排布，展开时在右侧显示热搜和搜索发现。

### 大屏视频页

- 双屏与三屏采用分栏布局：左侧播放器，右侧简介、评论、相关视频或合集。
- 评论回复、UP 主主页、完整选集和 AI 总结在右侧栏展开，播放器保持原位，返回只关闭面板。
- 横向选集自动定位当前分集；加载占位与实际卡片尺寸一致，避免内容跳动。
- 进出全屏时连续调整播放区域，不重新打开视频；全屏控件避让系统手势区和挖孔。

### 竖屏短视频

- 上下滑信息流：单击/双击操作、弹幕、作者与关注、评论、投币、收藏、分享和合集。
- 预取后续视频的播放地址与媒体开头，切页时复用缓存；快速滑动不重建播放器。
- 暂停界面、进度条、底部播控、关联搜索和弹幕入口按参考设计统一比例，并适配大字号。
- 本机“不想看”过滤，以及可选的海外线路探测与回退。

### 稳定性

- 播放器：合并重复的播放请求，缓冲停滞或音频时钟停滞时有限次自动恢复，失败后提供重试，并修复销毁与复用之间的竞态。
- 下载：校验断点续传响应，暂停或失败时保留有效分段，元数据原子写入，取消后彻底停止。
- 迟到的网络响应不再覆盖新页面、新账号或新选集的数据；搜索、动态、评论和私信补充异步保护。
- 封面按显示尺寸解码并复用缓存，减少高分辨率屏幕的内存与卡顿。

开发期间试验过的封面“一镜到底”动画和评论点踩数量统计已移除。

## 本版改动

- 统一版本命名：应用内显示 **Beta 1.0 · 构建 6253**，系统显示 `1.0.0-beta`，不再使用 `3.0.0`。
- 更新检测只选择当前发布中已上传完成的签名 HAP，同版本不重复提醒，能识别后续 Beta。
- 修复播放器快速切换与进度操作、下载取消与落盘失败、搜索和动态的异步响应、聊天页生命周期、游客消息提示，以及评论管理的错行问题。
- GitHub 自动构建固定兼容环境，并纳入全部 Dart 回归。

- 完整 Dart 回归 375 项通过，1 项诊断构建测试按条件跳过。
- 官方验签、ZIP 完整性、原生库哈希和内嵌源码提交核对通过；HAP SHA-256 为 `6f7a7b954bc3e779c70bc0a4b359c69fdcafe6bf3ec52ba8ef67e85f4067da71`。

模拟器无法验证真实视频解码、弱网、账号服务和真机帧率，因此不承诺所有设备流畅无缺陷。
