# V2 验证记录

日期：2026-09-21。应用版本：`2.2.0+6083`。源码分支：`harmony/v2-native-ui`。
V1 回退标签：`harmony-v1.0.0`。本页严格区分代码实现、自动测试和实际设备验证。

## 使用入口

在「设置 → 鸿蒙特色功能」中：

| 选项 | 默认 | 行为 |
| --- | --- | --- |
| 鸿蒙界面风格 | 关闭 | 统一设置面板、开关、弹层、按钮、输入框和已有加载动画，使用原生 HDS 导航 |
| 展开时保留悬浮 Dock | 开启 | 配合鸿蒙界面或 HDS 导航，在双折、三折展开后继续显示底部 Dock |
| 智感握姿 | 关闭 | 系统 HDS Dock 与已有全屏播放按钮按系统握持侧适配；拖动期间冻结按钮位置 |
| 全屏跟随折叠形态 | 开启 | 展开时解除旧的固定方向并交由系统方向策略处理；可关闭 |
| 视频封面一镜到底动画 | 关闭 | 只在封面与播放器矩形之间过渡，保留播放器状态；开关后按提示重启 |

鸿蒙风格使用 Flutter 共享组件和系统 HDS 导航，不是所有业务页面重写为 ArkUI。
原有业务布局、状态和回调继续复用。未增加原本没有的加载场景；具有业务含义的下载、投票、播放进度条保留。
