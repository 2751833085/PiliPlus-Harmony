# V2 验证记录

日期：2026-09-21。应用版本：`2.2.0+6084`（RC2）。源码分支：`harmony/v2-native-ui`。
V1 回退标签：`harmony-v1.0.0`。本页严格区分代码实现、自动测试和实际设备验证。

## 使用入口

在「设置 → 鸿蒙特色功能」中：

| 选项 | 默认 | 行为 |
| --- | --- | --- |
| 鸿蒙界面风格 | 关闭 | 统一设置面板、开关、弹层、按钮、输入框和已有加载动画，使用原生 HDS 导航 |
| 导航布局 | 悬浮 Dock | 可选悬浮 Dock、底部导航或侧栏；接管后原外观页中的 MD3/悬浮底栏/侧栏/优化平板导航选项禁用，点击说明原因 |
| 展开时也采用悬浮 Dock | 开启 | Dock 模式下可选展开保留 Dock，关闭则宽屏使用鸿蒙侧栏 |
| 采用鸿蒙原生配色 | 关闭 | 哔哩哔哩粉色与鸿蒙底色；禁用原调色和纯黑主题，关闭后恢复保存的设置 |
| 沉浸光感 | 开启 | 鸿蒙风格子选项；系统 Dock/顶栏材质和二级 Popup 光感表面独立开关 |
| 智感握姿 | 关闭 | 系统 HDS Dock 与已有全屏播放按钮按系统握持侧适配；拖动期间冻结按钮位置 |
| 全屏跟随折叠形态 | 开启 | 展开时解除旧方向锁定；折回单屏退出全屏回到详情内播放器，继续播放；可关闭 |
| 视频封面一镜到底动画（测试版） | 关闭 | 只在封面与播放器矩形之间过渡，保留播放器状态；开关后按提示重启 |

鸿蒙风格使用 Flutter 共享组件和系统 HDS 导航，不是所有业务页面重写为 ArkUI。
原有业务布局、状态和回调继续复用。未增加原本没有的加载场景；具有业务含义的下载、投票、播放进度条保留。

## RC2 补充

- “我的”改为有界账号/快捷功能/收藏分区，宽屏分栏；设置使用有界分组卡片，搜索框保持至少 48dp 可点高度，避免重复套胶囊。
- 子选项仅在开启鸿蒙界面风格后出现，同类功能分组；关闭后恢复原配色和导航偏好，不覆盖旧值。搜索结果同步更新，可用性检查覆盖搜索入口。
- 发布动态移除鸿蒙模式下竞争的拖拽容器，标题/发布按钮采用有界横向布局，话题可换行、发布权限等选项可自动换行，输入框移除不合适的胶囊边框。
- 鸿蒙加载使用 ArkUI `LoadingProgress` 平台控件；减少动态效果/未显示时停转。其他平台保留绘制后备。只替换已有加载点。
- 下拉后列表保持刷新位移，刷新 Future 完成再回弹；无新增网络或加载入口。
- “其他设置”提供可选哔哩哔哩式播放器控制栏，进度与常用按钮同一行，渐显渐隐，四边渐变遮罩；更多控制保留原动作。V2 中竖屏短视频入口先禁用，后续按用户最新要求在 V2.5 中完成。
- 系统 Dock/顶栏直接使用原生材质；Flutter Popup 使用局部模糊与半透明表面，保留 SDK 菜单焦点、禁用和选择行为，不宣称全部弹层都是 ArkUI 原生控件。
- 用户确认 RC1 的物理展开播放、方向和左右手握姿测试正常。新增“折回单屏退出全屏”尚未获得实机操作反馈。
- RC2 已签名覆盖安装成功，签名的代码/摘要/权限校验通过。随后手机锁屏，`aa start` 返回 10106102，未尝试绕过锁屏或关闭开发者模式。因此 RC2 的实际页面/原生加载效果与性能尚待解锁验证。
