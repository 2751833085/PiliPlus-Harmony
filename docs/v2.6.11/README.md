# V2.6.11 · 选集与返回交互

短视频的合集入口现在读取当前视频的真实合集和分 P 数据，复用原有选集面板与播放器换集逻辑。两者同时存在时，通过「合集 / 分 P」标签选择；分 P 继承所属视频的 BV/AV 标识，保留 CID、分 P 标题和画面信息。跳转准备结束前暂停上下翻页，避免把选择应用到其他视频。没有内容的合集隐藏入口。

关联搜索和合集入口改成同一行等宽显示，保留原来高度，单独出现时占整行。文字太长时省略，完整搜索词仍正常传递。

返回按当前界面逐层处理：投币、选集等弹层 → 评论 → 播放器全屏/视频页。弹层注册自己的返回拦截，不再依赖 Get 缓存的底层路由；播放器只处理自身阻止的返回，不会在评论关闭后又退出视频。播放器全局 Key 仍指向有状态组件，保留折叠和预初始化使用的挂载检查。

暂停和播放保持用户选择的信息层显隐状态。信息层隐藏时，仅切换底部播放/暂停图标，进度条不移动；信息层显示时，仍可使用中央暂停展示。缩小和全屏使用向内/向外的对角箭头。评论排序为灰色，评论、选集和弹层表面使用协调的深灰色。

普通播放器启用「原版播放器控制」时，手机也将播放、进度、时间和操作放在同一行。短时间字符串按自身宽度排版；长时长与大字号只在时间所在区域缩小，保留可拖动的进度轨道。无附加标记时组件回归为 48dp 总高，开启章节与弹幕趋势时至多 63dp；这些是组件测试结果。非全屏传统样式也减少垂直留白。空降标记、章节跳转、趋势和进度回调保留。
