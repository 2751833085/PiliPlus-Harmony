# V2.6.12 · 统一贴底菜单与沉浸光感

播放器顶部“更多”整合视频操作与播放控制；原版风格底部移除第二个更多入口，保留播放、进度、时间、竖屏与全屏入口。主面板使用紧凑操作网格和清晰列表，倍速、字幕、翻译和比例用完整选择行。原有音质、解码、顺序、定时、CDN、字幕导入导出等保留在“更多播放设置”。未播放时的更多菜单也采用同一贴底风格。

鸿蒙风格下，共用 PopupMenuButton / showMenu 的二级菜单统一改为贴底面板；设置选择、评论排序等沿用原回调、禁用状态和返回结果。关闭鸿蒙风格恢复普通菜单。沉浸光感扩展到菜单、播放器/弹幕设置、选集、我的卡片和关于分区；每块面板只用一个裁切后的模糊背景，高对比度、减少动态效果或关闭光感时使用实色。

修正根导航弹层丢失局部主题，以及播放器面板从错误上下文取色。视频深色背景、评论、选集和已关注状态采用中性暗色，消除种子主题色残留；自定义图片占位在失败时同样生效。选集与章节面板保留原点击/播放逻辑。

短视频切换保留信息流模式，不插入详情页封面；相邻页使用服务端提供的首帧，缺失时保留黑色视频背景，媒体仍沿用有界预加载和单播放器切换。首帧按 BV/CID 匹配、按账号隔离、限制缓存数量。它不能保证冷网络和解码器切换绝无等待。竖屏源禁用封面 Hero。

三折全展开全屏时隐藏顶部滚动标题；按物理窗口尺寸区分 Mate XTS 双屏/三屏，不受应用显示缩放影响。全屏时间轴不再被智感握姿缩成右侧 640dp 条，保持整段可拖动范围；主导航 Dock 仍可随系统握姿移动。

“我的”快捷入口收紧为自适应紧凑布局。关于页新增鸿蒙分区、开发历程与工作流，署名“厄斯因二次编辑”，保留上游来源、版本、日志和数据管理功能。
