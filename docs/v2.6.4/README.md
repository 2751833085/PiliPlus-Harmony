# V2.6.4 · 模式过渡与短视频反馈

普通与短视频模式切换时，当前页面先淡出，再以同一个播放器切到新布局并淡入。过渡共 280ms，不创建第二个播放器；系统启用减少动态效果时直接切换。返回普通模式的按钮改为缩小图标。

短视频评论顶部仅保留一行评论标题、排序和关闭按钮，标准字号下高 48dp。移除原来重复的拖动条、标题区域；评论排序、刷新、回复和二级评论继续使用既有业务。

短视频右上角三点菜单新增“我不想看”，选择“不感兴趣”“已经看过了”或“内容不符合预期”后跳过当前视频。当前页槽位保持不变，已有上一条导航保留；无法加载替代视频时保留当前视频并允许重试。菜单取消不会提交任何反馈。

相关视频与网页推荐数据没有提供服务端反馈原因 ID，因此此功能明确标注仅在本机短视频推荐中生效，不调用点赞/点踩、拉黑等账号接口。记录保存在设置中，最多保留最近 1000 条；通过同一原因菜单的“恢复本机已隐藏的视频”可清除。直接从搜索、收藏等位置打开视频不受过滤影响。
