# V2.5 · 竖屏短视频

此阶段按用户 2026-09-21 授权，将原 V3 计划提前为 V2.5。包含 V2 RC2 的全部界面与功能修正；仅本地开发和归档，不 push。

## 使用

在「设置 → 其他设置 → 播放器体验」手动开启「竖屏短视频模式」（默认关闭）。随后打开普通投稿视频即可进入竖屏信息流。右下角「普通详情」保留当前播放器与进度，返回原来的简介/评论布局；原播放器的竖屏按钮可以再次进入信息流。关闭开关后该按钮隐藏，普通视频恢复原布局。

「哔哩哔哩式播放器控制栏」是独立选项：开启后普通播放器使用紧凑控制栏、渐显渐隐与四边阴影。竖屏模式实现后才显示其切换按钮。旧的 V3 不可用占位已移除。

## 已实现的业务连接

| 操作 | 实现 |
| --- | --- |
| 上下滑动 | 使用已有相关视频接口接续队列、按 BV 去重、向前返回；末尾无结果时保留当前视频，失败可重试 |
| 播放与暂停 | 复用当前播放器；单击暂停/继续，长按沿用倍速；短视频播放结束循环当前视频，互动视频分支与睡眠定时优先 |
| 进度与弹幕 | 原进度/缓冲状态与 seek 回调，弹幕开关、发送面板及既有字幕；没有另建解码器 |
| 作者与互动 | 作者主页、关注、点赞/双击赞/长按三连、评论面板、投币、收藏/长按选文件夹、分享，均复用现有账号业务 |
| 合集与分 P | 打开原选集面板；选集同步当前队列项，后退/前进保留 |
| 更多 | 沿用原播放器设置，保留下载、稍后再看、音频、举报等既有功能；未开播时使用普通视频更多菜单 |
| 普通详情 / 全屏 | 同一播放器 GlobalKey 移动，状态和进度保留；全屏沿用 V2 折叠和系统握姿策略 |
| 窄屏与展开屏 | 黑色背景、安全区、600 逻辑像素内容上限；大字号操作区可滚动，时间与底栏分行避免挤压 |
| 手动启用 | 不依赖鸿蒙风格开关；默认关闭；番剧、直播、本地文件和批量播放列表保留专用页面 |

推荐内容来自项目现有哔哩哔哩相关视频接口，并非复刻官方应用私有推荐算法。账号权限、风控、付费视频限制继续由服务端决定。

## 稳定性处理

- 页面只保留一个活动播放器，邻页只展示封面；不创建多路隐藏视频，也不预下载下一条视频流。
- 取流和原生播放器初始化排队执行；新请求使旧票据失效，网络响应返回后先检查来源。
- 慢网络切换时保留旧播放器视图，直到新页面接管。专项测试曾复现视图被分页组件提前销毁的问题，现已修复。
- 详情、在线人数、评论、字幕和关系响应丢弃过期数据。收藏/投币等回调检查目标，避免串到另一视频。
- 点赞等异步交互等待期间暂停分页切换；请求失败后解除锁定。关闭页面后不再回调已销毁状态。
- 竖屏信息流不因设备旋转自动进入全屏，仍可手动进入全屏并沿用折叠适配。

## 验证边界

自动验证与真实设备验收分别记录在 [VALIDATION.md](VALIDATION.md)。组件测试使用本地测试播放器，不替代鸿蒙解码、真实网络、手势帧率或账号写操作验证。
