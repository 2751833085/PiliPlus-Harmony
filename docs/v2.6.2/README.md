# V2.6.2 · 分页连续性与短视频自动播放

版本 `2.6.2+6088`，保留 [V2.6.1](../v2.6.1/README.md) 的手势自定义、简洁界面和下一条媒体预加载。

进入短视频模式、上下切换新视频时自动播放。普通详情页的「自动播放」偏好不会被改写；当前视频依然可双击暂停，下一条重新自动播放。

此前 `onPageChanged` 在拖动刚过半页时便打开新媒体，并因切换状态更换滚动物理规则，容易中断拖动/吸附。现在在页面吸附结束后提交目标，滑过半页再拉回不触发换流。加载中仍可继续翻页，依次完成正在进行的请求与最终停留页，跳过排队的中间目标，避免请求并发抢占同一播放器。

原播放器保留在其页面中，直到最终可见目标准备好；中间目标即使已经退出页面构建范围，也不会先把播放器移入后随页面回收。换源期间隐藏旧纹理、显示对应封面，避免旧图出现在新视频位置。播放器始终只有一个。

相邻封面提前布局与解码，封面区域沿用播放器的底部控制区留白与 contain 比例，不再从整屏中心跳到视频区域中心。全屏仍使用完整可用高度。

这些调整针对分页中断、视图重建和封面几何位置；并不能保证任何网络下原生解码都没有首帧等待。真实设备的帧耗时与播放连续性需与组件回归分开验收。见 [验证记录](VALIDATION.md)。
