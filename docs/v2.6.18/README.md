# V2.6.18 · 切页首帧与刷新衔接

- 短视频播放器切换媒体、原生纹理暂时无尺寸时使用透明底，保留后方已预取的真实首帧，避免黑色填充把首帧遮住后再突然恢复播放。正常视频页的黑底不变。
- 首帧预览与正在播放的视频使用相同的底部控件高度计算，避免字号变化引起交接位置偏移。
- 鸿蒙下拉刷新从拖动开始保持同一个原生 LoadingProgress，不在松手时重建原生视图；刷新等待期间保留内容位移，结束后整体收回。
- 星球在下拉露出的区域内居中，并避开原生顶栏；弹性滚动已经产生的位移不会重复叠加。
- 「其他设置 → 刷新滑动距离」增加并默认选择「默认（原版下拉距离）」，沿用原来的 0.25 参数及滚动物理规则。原来的自定义值保留，可重新选择自定义。
- 「上次看到这里 → 点击刷新」先回顶，再通过同一刷新指示器触发请求。
- 松手是否触发刷新，先根据手指结束时的位置判断，避免首个回弹帧把已到阈值的下拉重新判成未到阈值。

本版未增加新的加载场景，也未增加第二个解码器。[验证记录](VALIDATION.md)。
