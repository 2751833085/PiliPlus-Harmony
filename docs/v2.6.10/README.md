# V2.6.10 · 圆角与普通播放器

修复三屏普通视频页当前时间和总时长上下堆叠的问题。原来的自绘时间固定为两行，现使用同一基线的「当前时间 / 总时长」，保留系统字体、文字缩放和读屏信息。原版风格控制条在宽窗口将剩余空间交给进度条，时间只占自身宽度；小于 600dp 的播放器将进度条独立放到按钮下方，避免短轨道和时间挤压。原始风格仍保留原有按钮分组。

进度条的命中区域为 28dp。空降片段的高度和位置随实际轨道计算，章节与弹幕趋势排列在轨道上方；开关这些覆盖层时不替换播放器、进度来源或跳转回调。章节鼠标点击、手机章节菜单保持原有分工。

评论面板在底部及侧边布局均使用四角 20dp 圆角；鸿蒙底部弹窗与对话框使用四角 28dp 并裁切内部背景，防止列表内容盖住圆角。搜索/合集卡片、弹幕列表补齐最外层裁切。普通风格底部面板统一为四角 18dp；评论编辑、视频及直播弹幕发送面板复用同一圆角并裁切内部背景。发弹幕、关注及评论入口使用同一个胶囊背景与按压形状；透明点击区域仍至少 44dp。设置搜索使用随高度变化的胶囊形状。分组设置的相邻行仍连接成完整卡片，视频画面保持自身矩形与比例。

[原生像素预览](previews/compare.html)由实际 Flutter 组件和测试数据直接栅格化；三屏 3184×2232、DPR 2.875 已从连接设备读取。单屏 1008×2232、双屏 2048×2232 使用明确标注的参考密度扫描，不等同于逐形态实测。字体为本地从设备读取的 HarmonyOS Sans / Sans SC，仅供测试，未入库或打包。安全区仍为模拟值。
