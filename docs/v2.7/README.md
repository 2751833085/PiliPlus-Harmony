# V2.7 · 首页栏数、刷新与评论交互

版本 `2.7.0+6106`。保留我的页和动态页的大结构，本轮集中调整首页、视频评论及小范围光感表面。

## 首页布局

外观设置新增「首页布局」分区。默认按可用窗口选择栏数，每种形态可单独覆盖；单屏竖向支持单栏/双栏，其他形态支持 1–6 栏。分屏或窄窗口会减少栏数，保证卡片至少约 140dp 宽。

| 窗口形态 | 默认栏数 |
| --- | --- |
| 单屏竖向 / 横向 | 2 / 3 |
| 双屏竖向 / 横向 | 3 / 3 |
| 三屏竖向 / 横向 | 3 / 4 |

形态由当前逻辑窗口尺寸推断，短边小于 600dp 按单屏处理，其余窗口长边小于 1000dp 按双屏处理，再大按三屏处理；这不是读取硬件铰链数量。这样自由窗口、分屏和旋转也能适配。实际卡片宽度使用去掉侧栏、边距后的可用空间。

原有 DP 宽度值仍保留，新增高级开关默认关闭。开启后禁用栏数选项并解释原因；关闭后立即恢复首页栏数适配。其他列表默认使用原有 240dp 基准，避免改动已认可的动态等布局；高级自定义宽度仍按原有说明重启生效。

## 刷新

下拉阶段渐显原生加载组件，释放后保持同一个组件与下拉空间，网络请求完成后用 140ms 淡出，再回弹列表。指示器上移并限制继续下拉时的下移距离。默认触发阈值、用户保存的自定义值、回顶再刷新的入口保持可用。

## 视频与评论

打开评论不再切换为没有控制层的裸播放器。保留暂停/播放、进度条和弹幕入口；视频区域上下滑动仍切换视频，既有评论控制器随视频更新并丢弃旧请求。评论区域独立滚动，返回手势仍优先关闭评论。

宽度至少 600dp 且横向的窗口使用左右分栏；其他窗口按底部播控和文字尺寸预留播放器空间。评论标题栏与页面底色一致，避免浅色主题中的突出亮条。

关注、合集/搜索、评论入口和反馈原因控件复用有界光感表面。仅在现有沉浸光感设置生效时启用模糊；高对比度/减少动态效果时仍回退为实色。视频画面本身没有新增遮罩。
