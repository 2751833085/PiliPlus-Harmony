# V2.6.17 · 增量排错与内部整理

本轮保持原有路由、页面控制器、Flutter/ArkTS 目录和单播放器结构，只调整新增适配代码内部。

- **原生显隐调用**：补上等待原生返回，异步异常才会进入现有处理；重试增加版本检查，旧页面的隐藏请求不能在新页面请求之后再次重试。顶栏路由/页签条件统一由同一函数合并；可选壳能力缺失时回退 Flutter 页面。
- **预加载失败回退**：播放器已拿到本地缓存地址、但预取请求随后失败时，原实现会返回 404。现在在当前缓存窗口内将请求以 307 转回原地址；移出窗口、清理或未知地址仍返回 404。地址数量仍有上限，同一来源重试复用地址。
- **短视频队列快照**：只在追加、刷新、不想看替换、选集同步后更新不可变快照，播放状态/手势变化复用快照；旧快照不会随内部队列变动。预取一次读取同一份快照，减少重复分配。

修复针对可复现的自动场景；不据此宣称真实网络下所有卡顿已消失。构建、DevEco 运行和未完成项目另见 [验证记录](VALIDATION.md)。不 push。
