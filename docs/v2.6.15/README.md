# V2.6.15 · 我的历史预览与避让回归

在「设置 → 其他设置 → 我的页面」新增「在我的页面展示观看历史」，默认关闭。开启后以横向卡片展示最近 10 条历史，显示封面、标题和观看进度；点击沿用历史页的续播与内容类型分流。普通界面和鸿蒙界面均支持，关闭后保留原观看记录入口。未登录显示登录提示，不请求个人历史。

历史预览支持刷新、从播放页返回后更新、账号切换清空，以及失败重试。迟到的旧账号请求不能回写当前列表；收藏请求也补上对应保护。收藏长标题限制卡片宽度，历史卡片行高按字体缩放取整，避免大字号溢出。历史页对缺失 ID、标题和时间的数据增加空值处理。

全屏播放栏补充横屏顶部挖孔和底部手势区避让；用户显式移除安全边距的原有选项保持有效。图片查看器隐藏系统栏期间，当前挖孔仍合并到临时安全边距，避免旋转后只保留旧方向的信息。

本版是测试候选，不代表全部功能已验收。自动回归、组件截图、游客接口检查和真实设备操作分开记录，详见 [验收清单](TEST_PLAN.md) 和 [验证记录](VALIDATION.md)。不 push。

为保护原账号，增加仅编译期启用的游客 QA profile。正式包默认关闭；测试包将 Hive、下载和临时数据放入独立子目录，不注销或清理正式账号。它不是系统级应用分身：原生 WebView Cookie 和图片缓存仍可能共享，所以游客测试不得进入 WebView、清除缓存或进行登录/注销操作。
