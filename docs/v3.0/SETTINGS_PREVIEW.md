# V3.0 设置重组预览 · 3.0.0+6122

本次仅重组设置和统一平台过渡，不代表 V3 全部 UI 改造完成。现有首页、动态、我的、播放页和业务功能保留。

## 设置结构

- 外观按「主题与显示」「导航与首页」「首页布局」「界面与布局」「动态与消息」分组。
- 颜色选择始终可用。选色后仅替换按钮/选中状态等强调色，自动退出默认粉色预设，保持鸿蒙界面和明暗底色；不会关闭鸿蒙 UI。
- 「应用主题」及其子页改名为「颜色选择」；保留主题模式和纯黑主题，纯黑可与鸿蒙原生配色同时使用。
- 鸿蒙底栏/悬浮 Dock/侧栏及展开时保留 Dock 放到外观设置。首页标签、底栏项目顺序、启动页及自动收起等有效功能保留。
- 移除重复的 MD3 样式底栏、旧悬浮底栏、旧侧栏、优化平板导航栏入口；不删除它们的历史偏好。
- 鸿蒙界面风格、原生配色、沉浸光感、智感握姿、折叠方向及其他鸿蒙能力并入「其他设置」。原鸿蒙特色独立入口移除；旧路由仍可进入其他设置。默认使用鸿蒙风格；开关改为「Material You 界面风格」，开启恢复原版界面，关闭恢复鸿蒙界面，均在重启后生效。旧 harmonyUI 数据保留，但新开关默认关闭。
- 移除横屏适配开关：鸿蒙默认跟随系统方向/旋转锁定。旧横屏值仍供动态瀑布流等尚未显式设置的旧默认值使用，避免升级改变这些界面。
- 移除过渡动画选择。使用鸿蒙 Flutter SDK 的 `OpenRightwardsPageTransitionsBuilder`；不是 ArkUI Navigation 原生页面栈。旧动画偏好保留但在鸿蒙不再生效。

- 鸿蒙颜色页使用单色圆形选项，移除四色色块、调色板算法菜单及 Material 首页/导航预览；完整调色功能仅在 Material You 模式下显示。颜色卡片遵循沉浸光感设置。
- 同类设置选择菜单改为贴近对应行展开；长菜单内部滚动，窄屏自动约束范围。菜单保留沉浸光感，高对比度/减少动画使用实色。操作型底部面板保持原交互。

默认强调色为粉红色；已保存的用户颜色不覆盖。首页推荐流首次加载不显示骨架卡片，仅底部一个加载指示，先淡出加载再淡入列表；错误态与重试保留，已有内容的刷新保持原列表。

## 实现边界

GetX 当前上游 fork 将 `Transition.native` 在非 iOS 平台固定映射为 Android Zoom。为准确接入 SDK 平台动画，将已锁定的 GetX 源码放入 `packages/get` 并做一个鸿蒙分支补丁，保留许可证、来源提交和其他平台逻辑。尊重系统减少动画设置。

## 6113 评论和刷新

- 普通视频评论页与短视频评论页共用底部评论栏，提示语为“尊重是评论打动人心的入场券”；文字区打开输入，表情按钮通过现有编辑器直接打开表情面板，不自动发送。

- 动态、已登录的“我的”首次加载使用统一单个指示器；未登录页面保持可访问。
- 取消刷新距离及高度设置，固定默认阈值。鸿蒙下拉位移限制为 88 逻辑像素；松手后指示器淡出，再刷新并动画收回内容，保留失败重试。

## 6114 刷新修正

此版替代 6113 的“先隐藏后请求”时序。鸿蒙使用明确的 96 逻辑像素拖动阈值，轻拉只让内容跟随，松手不足阈值取消；最多保留 88 逻辑像素下移。请求期间保留星球，结束后 220ms 渐隐，再回弹内容。自动化覆盖轻拉、足量下拉、保持、渐隐、回弹和程序刷新。

“我的”滚动卡片保留中性渐变和高光，禁用不必要的实时背景模糊并加入绘制隔离；弹出面板等仍保留实时模糊。此为绘制开销优化，不代表已证明所有设备帧率。

## 6116 最终简化方案（替代上述 6113/6114 下拉效果）

鸿蒙刷新不再让内容下移、悬停、回弹。只有在列表顶部下拉达到 180 逻辑像素阈值并松手后才请求，按住不会触发，轻拉与普通滚动不会创建星球；刷新中在底部 Dock 上方显示单个加载指示，完成后消失。分页继续加载不额外显示星球。松手触发、长按不触发与固定内容已在三种原生分辨率、两种滚动物理下自动验证。

图标绿色 P 替换为 #FB7299；四个绿色前景资源的尺寸、透明度和非绿色像素完全保留，背景未改动。“我的”实时模糊减负优化继续保留。

## 6121：常用分类优先、隐私集中与特色功能

- 播放器：控制栏、短视频、手势、折叠全屏、播放跳过、详情展示及弹幕字幕。
- 音视频：画质、音质、解码、缓冲、CDN、海外模式、网络安全及连接重试。
- 个性化：推荐、过滤、搜索、评论与动态偏好。按后续要求保留独立隐私入口。
- 隐私：黑名单、账号模式、搜索/评论记录、发评可见性检查、观看历史展示、代理与证书验证。

## 6122：换片首帧交接与相邻评论预加载

- Material You 开关移至外观设置末尾，常用画质/播放选项提前。
- 短视频上下翻页时，预览绘制在播放器纹理上方；以当前媒体源的视频时间戳确认画面就绪，再等待两次绘制回调淡出，避免旧源或尺寸事件过早揭开黑色纹理。
