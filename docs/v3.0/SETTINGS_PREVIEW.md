# V3.0 设置重组预览 · 3.0.0+6109

本次仅重组设置和统一平台过渡，不代表 V3 全部 UI 改造完成。现有首页、动态、我的、播放页和业务功能保留。

## 设置结构

- 外观按「主题与显示」「导航与首页」「首页布局」「界面与布局」「动态与消息」分组。
- 颜色选择始终可用。选色后仅替换按钮/选中状态等强调色，自动退出默认粉色预设，保持鸿蒙界面和明暗底色；不会关闭鸿蒙 UI。
- 「应用主题」及其子页改名为「颜色选择」；保留主题模式和纯黑主题，纯黑可与鸿蒙原生配色同时使用。
- 鸿蒙底栏/悬浮 Dock/侧栏及展开时保留 Dock 放到外观设置。首页标签、底栏项目顺序、启动页及自动收起等有效功能保留。
- 移除重复的 MD3 样式底栏、旧悬浮底栏、旧侧栏、优化平板导航栏入口；不删除它们的历史偏好。
- 鸿蒙界面风格、原生配色、沉浸光感、智感握姿、折叠方向及其他鸿蒙能力并入「其他设置」。原鸿蒙特色独立入口移除；旧路由仍可进入其他设置。关闭鸿蒙风格时条件选项立即更新。
- 移除横屏适配开关：鸿蒙默认跟随系统方向/旋转锁定。旧横屏值仍供动态瀑布流等尚未显式设置的旧默认值使用，避免升级改变这些界面。
- 移除过渡动画选择。使用鸿蒙 Flutter SDK 的 `OpenRightwardsPageTransitionsBuilder`；不是 ArkUI Navigation 原生页面栈。旧动画偏好保留但在鸿蒙不再生效。

- 调色板风格及同类设置选择菜单改为贴近对应行展开；长菜单内部滚动，窄屏自动约束范围。菜单保留沉浸光感，高对比度/减少动画使用实色。操作型底部面板保持原交互。

## 实现边界

GetX 当前上游 fork 将 `Transition.native` 在非 iOS 平台固定映射为 Android Zoom。为准确接入 SDK 平台动画，将已锁定的 GetX 源码放入 `packages/get` 并做一个鸿蒙分支补丁，保留许可证、来源提交和其他平台逻辑。尊重系统减少动画设置。
