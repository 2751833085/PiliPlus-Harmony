# V3 Beta 6216

本轮基于 6215，不改变已确定的过渡动画时长。

- 删除视频封面“一镜到底动画”的设置、偏好读取、封面 Hero 组件和播放器 Hero 包装。普通页面导航、图片查看器及播放器实例标识保留。
- 关于页开发历程整理为 V1 初步移植、V2 界面适配、V3 全面优化。
- 推荐刷新可同时请求两页，最多请求四页，按请求顺序去重；单页失败时保留另一页成功结果。网页推荐仍顺序请求，避免重复的大批量请求。
- 当前所选画质已经可播放时，先初始化播放，后台补充其他画质；所选画质缺失时仍等待必要信息。
- 评论 @ 名称加粗高亮，优先匹配较长名称，避免昵称前缀冲突。现有接口没有提供“被提及用户拉黑评论作者”的可靠关系字段，因此不展示推测的“已被拉黑”标记。
- 聊天页面、输入面板、安全区域和系统底栏使用相同背景，保留安全区高度。
- 更新检查切换到 `2751833085/PiliPlus-Harmony`，用版本号和构建号比较，过滤草稿、无效标签和没有 HAP 的版本；支持本项目 Beta 发布，下载指向选定版本的 HAP。
- 发布标签格式为 `v3.0.0+6216`；构建脚本从 pubspec 读取版本，不再用提交数量覆盖版本号。
