## 已实施

- 鸿蒙构建统一鸿蒙风格，移除 Material You 可见设置。保留强调色、明暗/纯黑、字号和沉浸开关；不清空旧偏好。

- 沉浸表面共用触点高光、轻拉位移和释放回弹。滚动超过局部反馈范围便释放，不抢手势；最深层表面响应。缓存静态子树，列表表面不逐项实时模糊，无触摸时无持续动画。
- 通用按钮、开关、短菜单、确认对话框、无痕提示、Toast 统一材质。短菜单锚定触发点，长视频功能面板继续贴底。统一短距离淡入转场。
- 消息采用宽屏列表/内容双栏、窄屏逐级浏览；显式会话身份，保持折叠时的草稿/焦点/滚动，按需创建当前会话/通知控制器。发送失败释放发送锁，不向真实联系人发送测试消息。
- 我的收藏/历史删除独立刷新；新增课程、装扮、会员购和订单中心官方网页入口。设置左栏加宽；动态卡片及 UP 筛选统一表面；搜索纵向热搜、历史、发现，复用完整榜单入口。
- 历史/订阅/离线/横向视频条目和稍后再看播放全部补充表面。离线封面移除绘制路径中的同步文件存在检查。
- 首页刷新阈值从 .25 微调为 .22，仍需过阈值松手；保持原刷新转圈，补背景材质。
- 短视频保留单播放器和详情/头像/底栏随页翻动；邻近预加载优先当前滑动目标及方向，最多三个候选，保留原有有界媒体/评论缓存；评论动画缓存静态子树。
- 握姿统一系统事件到原生和 Flutter；重复同值样本不重启去抖；LEFT/RIGHT/BOTH 分别左右居中；触摸原生 Dock 时冻结位置；区分等待、无权限、不支持及有效状态。
