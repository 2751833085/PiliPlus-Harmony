## 刷新依据与实现边界

依据 ArkUI Refresh 官方文档：默认64vp，内容随手势下移，松手后才触发；阻力随距离增加。
https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-container-refresh
https://raw.githubusercontent.com/openharmony/docs/master/zh-cn/application-dev/reference/apis-arkui/arkui-ts/ts-container-refresh.md

Flutter列表仍由Flutter处理手势与滚动；加载指示器通过既有平台视图使用ArkUI LoadingProgress，并非将Flutter整个列表替换为ArkUI Refresh。刷新采用固定64逻辑像素视觉阈值，渐进阻力，完成后淡出再收回。不按屏幕高度放大门槛。首页同一底栏按钮350ms内两次点击刷新，首次点击仅回顶；首页刷新请求去重。
