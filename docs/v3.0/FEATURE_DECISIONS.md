# V3.0 功能去除与合并台账

用户将逐项指定去除/合并内容。本表同时记录候选与已确认决定；以最新用户指示为准。

| 功能/设置 | 候选整理方向 | 用户决策 | 数据迁移/验收注意 |
| --- | --- | --- | --- |
| Material / 鸿蒙界面风格切换 | 正式 Beta 只保留鸿蒙风格 | 最新用户决定：移除 Material You 显示与开关；先完成计划再实施 | 6125 仍为双风格基线；升级迁移只改风格，不清空其他设置 |
| MD3 底栏、悬浮底栏、旧侧栏、鸿蒙导航设置 | 合并成一处导航与展开布局设置 | 已确认：移除重复入口，鸿蒙导航放外观设置；见 SETTINGS_PREVIEW.md | 历史值保留，保持现有界面 |
| 原主题调色、鸿蒙原生配色、沉浸光感 | 颜色选择与界面风格独立 | 已实现：颜色始终可选；纯黑保留；选色不关闭鸿蒙风格 | 光感位于其他设置的鸿蒙分区；默认粉色作为可替换预设 |
| 普通/仿原版播控、短视频入口 | 统一播放体验设置和明确的模式切换 | 待用户确认 | 不意外改变默认进入规则、手势或自动播放 |
| 上下更多菜单、合集、字幕与倍速入口 | 按任务分组，统一弹层行为 | 待官方观察与用户确认 | 保留每项能力和返回优先级，不能只删入口 |
| 首页栏数、DP 限制、横屏适配 | 自适应布局和高级覆盖 | 已实现：保留栏数与可选 DP；横屏改为自动 | 保留已保存值及无关旧默认 |
| 非鸿蒙平台构建与专用设置 | 单独评估清理目录及依赖 | 待用户确认 | 有些依赖是解析/构建所需，不能按名称直接删 |
| 账号、缓存、历史、收藏、稍后再看、关注/订阅 | 默认保留 | 未指定删除 | 覆盖升级不得丢数据；“合并入口”不等于“合并数据” |
| 空降、字幕、翻译、弹幕、海外模式、后台播放 | 默认保留 | 未指定删除 | 必须保留回归与平台能力约束 |
| 用户后续新增条目 | 记录原话、最终入口、删除边界和迁移规则 | 待输入 | 决策完成后再进入开发任务 |

设置中的值选择 Popup（例如调色板风格）已改为对应行附近的菜单，并支持沉浸光感。播放器等操作面板不因本次调整变成设置式小菜单。

正式 Beta 最新范围以 [全界面改造计划](BETA_PLAN.md) 为准；本表早期“已实现”条目是历史状态，不代表新的删除授权。

最新用户决定：首页现有设计保留，不重做；所有弹出菜单、对话框和提示统一配色与沉浸光感，包括无痕模式提示。弹出位置仍按用途区分，见 BETA_PLAN.md。

最新细化（计划阶段）：我的、设置和播放页主要布局保留；收藏/历史刷新按钮全部删除；我的新增“我的服务”（课程、装扮）及“订单中心”；设置展开左栏加宽；动态改成协调的卡片式信息流；全部按钮/菜单/提示统一光感及互动，短操作菜单就近展开；首页刷新阈值小幅降低且仍松手触发。具体范围及服务实现边界见 BETA_PLAN.md 第八节。按钮交互已明确为跟手高光、轻拉弹性反馈和松手回弹，适用于全部沉浸光感按钮/控件；不增加自由摆放。

光感交互最新确认：所有使用该材质的控件都要补齐与 Dock/首页搜索栏同类的触点高光和弹性拉动回弹，不能停留在静态外观适配。见 BETA_PLAN.md 第九节。

智感握姿：用户确认真实左手靠左、右手靠右、双手居中，不以左右滑动代替握持识别。列为 Beta 优先修复项，统一原生 Dock 与 Flutter 控件状态源；系统事件/权限仍需真机验证。

最新决定：Dock 提高遮蔽与内容对比度，保留光感/弹性；搜索展开页改为热搜→历史→搜索发现纵向排列，热搜旁保留并突出已有完整榜单入口。首页搜索栏不改，已有隐私/显示偏好保留。覆盖此前搜索主布局不改的计划，见 BETA_PLAN.md 第十一节。

底栏最新决定：仅“悬浮”“经典”两种；经典为固定贴底的原版底栏。移除主导航侧栏选项及重复展开控制，展开保持所选类型。内容分栏保留，旧设置按显式映射迁移，见 BETA_PLAN.md 第十二节。
