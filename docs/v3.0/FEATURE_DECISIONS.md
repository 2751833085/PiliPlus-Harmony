# V3.0 功能去除与合并台账

用户将逐项指定去除/合并内容。本表是讨论候选，不是自动执行清单；研究阶段没有删除功能。

| 功能/设置 | 候选整理方向 | 用户决策 | 数据迁移/验收注意 |
| --- | --- | --- | --- |
| Material / 鸿蒙界面风格切换 | V3 面向用户固定鸿蒙风格，旧实现迁移后删除 | 已明确总体方向；具体迁移待实施 | 老设置升级后不再导致回退到 MD |
| MD3 底栏、悬浮底栏、旧侧栏、鸿蒙导航设置 | 合并成一处导航与展开布局设置 | 待用户确认 | 保存旧偏好映射，避免方向/折叠后导航消失 |
| 原主题调色、鸿蒙原生配色、沉浸光感 | 一套主题与材质设置 | 待用户确认 | 深浅色、可读性、可选光感保持独立含义 |
| 普通/仿原版播控、短视频入口 | 统一播放体验设置和明确的模式切换 | 待用户确认 | 不意外改变默认进入规则、手势或自动播放 |
| 上下更多菜单、合集、字幕与倍速入口 | 按任务分组，统一弹层行为 | 待官方观察与用户确认 | 保留每项能力和返回优先级，不能只删入口 |
| 首页栏数、DP 限制、横屏适配 | 合并为自适应布局和高级覆盖 | 待用户确认 | V2.7 值需要迁移映射 |
| 非鸿蒙平台构建与专用设置 | 单独评估清理目录及依赖 | 待用户确认 | 有些依赖是解析/构建所需，不能按名称直接删 |
| 账号、缓存、历史、收藏、稍后再看、关注/订阅 | 默认保留 | 未指定删除 | 覆盖升级不得丢数据；“合并入口”不等于“合并数据” |
| 空降、字幕、翻译、弹幕、海外模式、后台播放 | 默认保留 | 未指定删除 | 必须保留回归与平台能力约束 |
| 用户后续新增条目 | 记录原话、最终入口、删除边界和迁移规则 | 待输入 | 决策完成后再进入开发任务 |
