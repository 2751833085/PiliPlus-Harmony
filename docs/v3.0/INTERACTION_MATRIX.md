# 官方鸿蒙版交互观察矩阵

样本版本 8.47.1 / 8471100，2026-09-23。本表区分直接观察、局部验证和待验证；以前的 iOS 截图不作为官方鸿蒙版行为证据。

| 场景 | 当前证据 | 状态 | V3.0 需要形成的规则 |
| --- | --- | --- | --- |
| 单屏沉浸播放的横向视频 | 底部弹幕入口旁有点赞/投币/收藏/评论，合集在进度条上方 | 直接观察，不能推广到所有视频 | 分别定义横向与竖向素材、普通与沉浸播放的布局 |
| 评论打开 | 下方评论面板，上方视频区域，底部固定输入入口 | 直接观察 | 弹层尺寸、视频缩放、暂停/进度可达性 |
| 系统 Back 关闭评论 | 单次 Back 后评论控件树消失，下层播放页仍在 | 局部验证；截图间内容切换，连续性未确认 | 键盘→子面板→评论→播放页的逐级返回 |
| 首页推荐、分区与全局导航 | 尚未完成受控操作 | 待验证 | 顶部入口、底部页签、返回时滚动位置 |
| 单/双击、左右拖动 | 用户此前说明与 iOS 参考不能代替此版本实测 | 待验证 | 信息显隐与暂停独立、拖动优先级、可选手势覆盖 |
| 上下翻页、第一条下拉 | 当前能看到下拉刷新提示，未受控测量全过程 | 待验证 | 预取窗口、首帧承接、刷新阈值与完成动画 |
| 上下两个更多入口 | 未进入菜单执行受控观察 | 待验证 | 是否统一入口、菜单分组与底部贴附 |
| 合集/分 P | 已观察合集入口及展开文案 | 入口已见，选集流程待验证 | 同源切集、播放位置与评论源切换 |
| 双屏/三屏、旋转、锁定 | 本轮只有单屏 1008×2232 | 待物理验证 | 窗口宽度、纵横比、安全区共同驱动布局 |
| 我的与动态 | 本项目用户已认可，官方尚未采样 | 待比较 | 保留现有信息组织，统一基础组件 |
| 搜索与设置 | 尚未采样 | 待验证 | 搜索返回、输入法、设置分组与生效时机 |

原始截图/控件树仅在本机 `/tmp/piliplus-v3-*`，不作为可长期访问的仓库附件，也不提交用户观看内容。后续受控采样应使用固定测试视频、固定主题/字号和记录过的屏幕形态。
