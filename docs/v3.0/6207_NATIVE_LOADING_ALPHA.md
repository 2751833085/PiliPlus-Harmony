# 6207 原生加载控件 alpha 通道

用户反馈6206的遮罩依然不能使星球本身从透明变清晰、完成后再透明。代码检查确认原生 HarmonyLoadingPlugin 仅接收 color、animate，Dart端透明度只作用在外层；原生 LoadingProgress 没有自己的动态 alpha 输入。

本次为每个原生视图创建独立 MethodChannel，更新 @Observed 状态，并由 @ObjectLink 将 alpha 应用到 LoadingProgress.opacity。创建参数也携带初始 alpha，避免平台视图异步创建时先完整闪现。拖动、完成渐隐始终使用同一个控件，不以透明度为key重建。Dart端最多保留一个在途更新，其余合并为最新值，销毁时停止发送，原生销毁时注销通道。

刷新保留6206的实际裁剪区域；星球自身接收由下拉距离和完成动画共同计算的0–1透明度。首屏加载淡出也使用同一原生alpha路径。非鸿蒙绘制路径保持Flutter Opacity。

验证：12项专项测试通过（原生通道数据、合并更新、旧视图换新、三种原生宽度刷新及外观回归）。这些测试包含模拟通道，不能声称已经验证原生合成画面的最终观感。鸿蒙编译、签名校验与安装结果记录在相邻发布元数据中。未推送GitHub。
