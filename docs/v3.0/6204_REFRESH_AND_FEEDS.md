# 6204 刷新与首页栏目修整

本轮参考用户提供的酷安鸿蒙端三张截图，统一顶部加载区与内容下移的位置关系。静态截图不足以测得酷安的时长和阻尼曲线，因此没有宣称复刻其内部实现。

- 下拉、松手刷新、完成渐隐期间保留同一个原生 LoadingProgress，避免从静止转入加载时销毁重建 OhosView。缩小为 24vp 中性色指示器，居中于拉出的留白；渐隐完成后内容收回。仍为 Flutter 手势协调、ArkUI 原生加载控件，非完整原生 Refresh 容器。
- 刷新内容增加独立绘制边界，拖动帧复用列表子树。推荐页快速滚动的分页回调按帧合并，并重新检查是否仍接近列表底部，防止过时回调继续请求。
- 直播卡片采用与推荐一致的 4:3 封面、6vp 间距、紧凑文字区和 4vp 圆角。番剧、影视卡片保留海报比例，统一间距和圆角。热门、排行榜保留横向卡片，清理为旧悬浮底栏预留的底部空白。直播与番剧网格不再永久缓存首次创建时的字号和宽度约束。
- 我的页面增加底部滚动余量（64vp 加安全区），使最后的稍后再看内容能完全滑到底栏上方。

验证：170 项鸿蒙适配回归通过；另有 3 项推荐/直播/番剧/搜索布局测试通过。布局覆盖 1008、2048、3184 原生像素宽，DPR 2.875，字号倍率 1.0、1.3、1.8。刷新专项同时验证松手前不请求、阈值、加载控件实例延续、渐隐先于内容收回。

静态检查无错误、无警告，有 7 条花括号风格提示。真实设备正在由用户使用，本轮不安装、不操作手机；未测量真机帧率，不能据此认定卡顿已全部解决。未提交或推送 GitHub。
