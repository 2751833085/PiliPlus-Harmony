# V2.6.6 · 短视频暂停界面

按用户最新提供的 iOS 截图，短视频暂停时显示作者、简介、右侧操作与半透明中央播放按钮；当前时间/总时间放在按钮下方。底部进度条、弹幕胶囊和模式按钮保留。

单击中央按钮立即继续播放；暂停时临时显示信息层，不改写此前的信息显隐偏好，恢复播放后按原偏好显示。播放中的简洁状态继续使用底部播控。

拖动进度时暂隐中央按钮与信息层，仅保留拖动反馈；缓冲、切换视频或时长尚未就绪时不误显示暂停状态。评论和全屏布局仍使用各自控件，视频区域及播放器实例保持不变。低高度窗口将中央按钮与时间紧凑横排，适应大字号。

包含 V2.6.5 的按比例入口、三条连续预取及此前全部功能。参考图只用于布局，不引入任何账号写入行为。
