# V2.6.3 · 底部播放控制

版本 `2.6.3+6089`，保留 V2.6.2 的分页、自动播放与预加载修复。

竖屏模式单击画面后，头像、简介及其他操作淡出；底部进度条、时间与播放/暂停按钮保留。按钮位于进度条左侧，48×48 逻辑像素触控区域，图标 28；暂停时原位变为播放按钮，不再显示画面中央按钮。

简洁模式可以继续点按、拖动进度条，也保留画面横向手势自定义。两种界面及播放/暂停切换不移动视频和底部播放行。底部留白统一计算，封面与播放器仍使用同一尺寸。全屏控制栏沿用现有布局。
